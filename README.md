# m2m-social-images

Temporary public hosting for Month2Month's Google Business Profile post images.

Google's API only accepts a public image URL for a GBP post. The weekly posting job
(private repo Month2Month/m2m-social-posts) adds the one image being published, creates
the GBP post, waits until Google has stored its own copy, then wipes this repo back to
this README (history included). Normally this repo is empty.
